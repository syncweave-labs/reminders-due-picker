# Security Policy

## Supported version

Security fixes are made on the latest `main` branch. Reinstall the app from
`main` after a fix is published.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** flow in the repository Security tab.
Do not open a public issue for a suspected vulnerability.

Include:

- the affected commit
- a minimal reproduction using synthetic reminders
- the security impact
- a suggested mitigation, if known

Do not include reminder titles or notes, Apple account identifiers, local
absolute paths, signing identities, crash reports with personal data, or
exported Reminders data. Redact those values before submitting a report.

The maintainer will acknowledge a report when it is reviewed, validate it
privately, and coordinate a fix before public disclosure when appropriate.
